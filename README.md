# MOTION — анализ приседаний

Мобильное веб-приложение на HTML, CSS и JavaScript. Живая камера, локальный видеофайл и анализ позы работают в браузере; содержимое видео не отправляется на сервер. При первом запуске нужны сеть и доступ к CDN для загрузки MediaPipe Tasks Vision и модели Pose Landmarker Lite.

## Запуск

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173` на том же устройстве. Доступ к камере на другом устройстве требует HTTPS (или другой поддерживаемый браузером защищённый контекст).

Выберите камеру или локальный файл, затем настройте и начните подход. Разместите человека целиком в кадре и встаньте прямо. Для оценки положения коленей выберите ракурс «Спереди», «Сбоку» или оставьте «Авто»; при промежуточном ракурсе автоматическая проверка может быть недоступна.

## Тренировочный подход

1. Нажмите «Старт камеры» или «Загрузить видео». До запроса доступа к камере или чтения файла откроется настройка: выберите 5, 10, 15 или 20 повторений, введите собственное положительное целое число либо включите **Свободный режим**. Нажатие **«Начать подход»** обнуляет результаты предыдущего подхода и запускает выбранный источник и анализ.
2. При заданной цели счётчик показывает выполненные и запланированные повторы (`X / Y`), а тонкая шкала — прогресс. В свободном режиме показываются число повторов и `∞`, без шкалы и автоматического ограничения.
3. На целевом повторе подсчёт и источник останавливаются автоматически, звучит короткий сигнал Web Audio API и открывается экран итогов. Нажмите **«Завершить упражнение»** вверху экрана, чтобы в любой момент остановить подход вручную: выполненные повторы сохраняются, сигнал не воспроизводится. Кнопка доступна и во время запроса камеры, загрузки модели или файла, а также при паузе и ошибке источника.
4. Итоги показывают повторы, цель и время с начала подхода, включая паузы и ожидание источника. **«Новый подход»** заново открывает настройки с последним источником; счётчик обнуляется после подтверждения старта.

Сигнал создаётся средствами браузера только при достижении цели; предупреждения техники по-прежнему исключительно визуальные и текстовые. Браузер, устройство или системные настройки могут запретить звук — это не мешает завершению и показу итогов.

Точка расширения для следующего этапа — функция `showWorkoutResults(result)` в `app.js`. Она получает неизменяемый снимок `{ reason, repCount, goal, durationMs }`: `reason` — `goal` или `manual`, `goal` равен `null` в свободном режиме, время указано в миллисекундах. Результат также сохраняется в `workout.lastResult` до старта следующего подхода; он не записывается на сервер или в постоянное хранилище.

## Источники видео

- Нажмите «Старт камеры» для живого изображения или «Загрузить видео», чтобы выбрать файл с устройства. Подходят MP4, WebM и MOV, если их видеокодек поддерживает браузер и операционная система; одно только расширение файла не гарантирует воспроизведение.
- После выбора файла камера останавливается, а ролик декодируется локально. Воспроизведение начинается после загрузки модели; если браузер запретил автозапуск, нажмите **Play**. Панель позволяет поставить видео на паузу, перемотать его и включить **Повтор**. Звук не воспроизводится.
- «Живая камера» освобождает локальный URL файла и снова запрашивает доступ к камере. Обе кнопки работают и во время загрузки источника; запоздавшие запросы камеры и ранее выбранные файлы не заменят актуальный источник.
- Смена файла или возврат к камере внутри одного подхода сохраняют счётчик и сбрасывают только незавершённый присед. То же происходит при перемотке и переходе на начало при повторе. Если ролик проигрывается заново, упражнения в нём считаются ещё раз. «Стоп камеры» приостанавливает источник, но не завершает подход; для итога используйте кнопку завершения вверху.

На паузе цикл распознавания не работает; первый кадр при загрузке и кадр после перемотки могут анализироваться один раз для обновления скелета. Время для MediaPipe берётся из монотонного `performance.now()` и остаётся строго возрастающим даже при перемотке, повторе и смене источника. Анализ идёт во время воспроизведения: если устройство не успевает, часть кадров и повторов может быть пропущена.

## Анализатор

`analyzer.js` экспортирует `SquatAnalyzer`. На каждом обработанном кадре передавайте ему нормированные landmarks первой позы MediaPipe:

```js
import { SquatAnalyzer } from './analyzer.js';

const analyzer = new SquatAnalyzer({ view: 'auto' });
analyzer.setFrameSize(video.videoWidth, video.videoHeight);
const { repCount, currentPhase, currentErrors, feedbackMessage } = analyzer.update(landmarks);
```

Передавайте `null`, если поза не найдена. Начальная фаза `WAITING` требует исходной стойки; затем доступны `STANDING`, `DESCENDING`, `BOTTOM` и `ASCENDING`. Нижняя точка подтверждается разворотом или паузой. Используется средний угол доступных коленей; при длительной потере позы незавершённый повтор отменяется. `resetTracking()` отменяет незавершённый повтор с сохранением счётчика, `reset()` обнуляет счётчик. `setView('auto' | 'front' | 'side')` задаёт ракурс.

`analyzer.getHighlightedSegments()` возвращает проблемные сегменты последнего обработанного кадра для отрисовки поверх скелета. Красным обозначаются превышение порога наклона корпуса и недостаточная глубина, жёлтым — замечания к положению коленей. Текст предупреждения сохраняется не менее 1,8 секунды, если его не заменяет более приоритетное; цвет скелета отражает текущий кадр.

Измерения приблизительны и зависят от камеры, ракурса и видимости суставов. Пороги заданы как программные ориентиры, а не медицинский диагноз; положение колена впереди носка само по себе не означает опасной техники.

## Проверка

```sh
node --test tests/*.test.mjs
```

Браузерные smoke-тесты используют небольшой тестовый WebM, синтетическую камеру и подменяют модель MediaPipe; тест подходов также подменяет Web Audio для проверки вызова сигнала. При желании установите Playwright вне проекта и запустите тест (пример для Linux/macOS):

```sh
npm install --prefix /tmp/motion-playwright playwright
/tmp/motion-playwright/node_modules/.bin/playwright install chromium
NODE_PATH=/tmp/motion-playwright/node_modules node tests/video.browser.cjs
NODE_PATH=/tmp/motion-playwright/node_modules node tests/workout.browser.cjs
```

Если Chromium уже установлен, его путь можно указать через `MOTION_CHROMIUM_PATH`. Файл `tests/fixtures/short.webm` — синтетический тестовый видеоряд, а не пользовательское видео.
